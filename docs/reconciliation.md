## Rules

- Filing values are parsed as printed (`(x)` = negative; commas, `$` and spaces removed) and multiplied by the statement units. A dash shown for zero is typed as 0.
- Match tolerance: the filing is rounded to its units, so MATCH means |app − filing| ≤ 0.5 × units (e.g. ±500,000 for millions). Differences are shown in the filing's units.
- `capex` and `interest_expense` are stored as positive amounts by the app, so their absolute values are compared. All other fields are compared with their sign.
- Statuses: MATCH, MISMATCH, NOT CHECKED (no filing value typed yet), APP VALUE MISSING (the app has no value; never treated as 0), NO APP ROW (no app row for that ticker/year/field), INPUT ERROR (filing value or units unreadable).
